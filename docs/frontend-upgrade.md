# 前端工作台升级说明

## 复用与调整

参考用户提供的 `ToastFish_Pro_v2.4_Source_Package.zip`，保留了浅色毛玻璃卡片、深色复习看板、双栏词典、双柱学习趋势及轮次弹窗的交互方向，使用现有 Vue 3 项目实现，不引入 Tailwind CDN 或外部字体。

压缩包中的演示词库、固定统计、手动加减的保持率、FSRS 参数变化、示例词根词频及开源集成开关不用于正式界面。当前后端仍使用 SM2plus，页面不声称已经接入 FSRS、ECDICT 或其他词典。

## 五页变化

- 首页：独立的新学与复习柱状图、真实学习指标、词库进度卡片、未完成轮次及原生通知入口。
- 记录：操作类型筛选、与当前查询一致的 Excel 导出、学习轮次复盘弹窗；默认日期从本周一开始。
- 我的单词：主从双栏词表与详情、当前页多选、快速切词、英美发音按钮、已有词库例句和学习时间线。详情面板支持独立滚动。
- 复习与错词：保留到期、评分遗忘、测验错词及专项词表，增加完整词库的复习到期时间分布。时间节点支持鼠标和键盘筛选。
- 词库与设置：统一卡片风格和处理状态，明确当前已接入能力；沿用原有 Excel 和 SQLite 备份格式，不替换为演示包的 JSON 备份。

## 时间轴含义

时间轴展示的是实际下一次复习时间与单词数量，不是个人遗忘曲线或记忆概率预测。

节点依次为：已到期、今天剩余时间、明天、2～6 天、7～13 天、14～30 天、31 天及以后、未排期。它们按电脑本地日期划分，统计范围为所选词库中已进入复习阶段的全部词条，不局限于当前列表页。

点击节点会切换为复习计划列表并筛选对应时间段；点击四类复习标签时清除时间限制，避免遗留隐藏条件。

## 只读接口代码变化

- 新增 `GET /api/reviews/overview?book=...`，返回复习阶段词条的各时间段数量。
- `GET /api/words` 增加可选 `window` 参数，支持时间轴筛选。
- `GET /api/records` 与 `GET /api/exports` 同时支持 `kind=ratings` 或 `kind=test`，保证表格与导出使用同一查询条件。

上述变化没有增加表、字段、迁移或新的数据库写入路径。本次没有启动桌面客户端或执行 SQL；后端只做编译检查。真实数据库查询和原生通知端到端联调尚未执行。

## 验证与边界

在 `Web` 目录使用 Node.js 22.12+ 和 pnpm：

```powershell
pnpm test
pnpm run build
```

`pnpm test` 的所有请求均被内存函数替换，不访问网络或数据库。浏览器交互检查使用静态预览服务和完全拦截的内存 API；操作不会转发到桌面服务。

静态预览 `pnpm preview` 不代理真实 API。日常开发仍通过 `pnpm dev` 的本机代理连接客户端；连接真实客户端并操作保存、学习、导入或恢复时会进入原有业务写入流程，不能作为无需授权的自动验证手段。

CI 已停用旧的数据库写入检查步骤。未经对具体数据库操作的明确授权，不运行旧的数据库测试脚本，不启动会初始化或迁移数据库的客户端。

浏览器朗读使用本机或浏览器提供的语音，不保证每台电脑都有对应的英美音色；不支持朗读时会禁用按钮或显示说明。通知背词按钮继续请求真实 Windows 通知，不在页面中模拟评分。

页面新增的统计需要配套编译后的本地服务。若仍运行旧版服务，时间轴会提示接口不可用，基础词表仍可使用。
