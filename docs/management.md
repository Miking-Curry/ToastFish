# 本地学习管理

## 使用

VS2022 中以 `ToastFish` 为启动项目，选择 `Debug / Any CPU` 后按 F5，会自动打开学习管理页；也可以从托盘右键“学习管理”再次打开。修改项目配置后按 VS 提示重新加载项目，启动前退出旧的 ToastFish，避免两个版本同时运行。Debug 和 Release 均使用下方同一用户数据库，不从输出目录读取学习进度。

1. 退出旧的 ToastFish，启动本次构建的程序。
2. 右键托盘图标，选择“学习管理”。浏览器会打开仅本机可访问的页面。
3. 首次注册本地地址若需要授权，确认程序提示后完成一次 Windows 管理员授权。程序日常不需要以管理员身份运行。
4. 首页选择词库开始学习，实际背词与测验仍在 Windows 原生通知中进行。
5. 点击通知正文只恢复当前卡片。通知被手动收起后，也可以按 Alt+Q 恢复。
6. 本轮可以暂停、继续或结束。结束保留已经保存的记录，不再继续未完成任务。

管理页包含首页、记录、单词、复习与错词、词库与设置。第一版管理英语；日语、五十音、自定义内容仍使用原托盘入口。

每次评分和答题会把事件、单词状态和轮次快照一起提交到 SQLite。重新启动不会重新抽取这一轮的单词；选择继续后恢复最后成功保存的题目或解析。未成功提交的操作仍需要重试。

## 数据位置与迁移

- 可写数据库：`%LocalAppData%\ToastFish\inami.db`。
- 首次运行从当前程序的 `Resources\inami.db` 初始化，此后更新或重新编译程序不会覆盖用户数据库。
- 学习日志在用户目录的 `Log` 文件夹；历史图表只统计新版本记录，不根据旧版单词清单推测过去的学习日期。
- 旧安装版与源码调试版的进度可能不同。若需旧安装版进度，先退出旧程序，进入“词库与设置 → 迁移旧安装版数据库”，选择其 `Resources\inami.db`。此操作只允许在尚无新版本学习事件时执行，并自动备份当前数据。
- 备份与恢复均在“词库与设置”中完成。恢复前验证完整性和数据结构，替换前自动备份；文件最大 128MB。
- 重置词库只重置学习状态，保留历史事件与专项词表。

默认本地地址为 `http://127.0.0.1:17653/`。若端口占用或授权取消，通知学习仍可使用；关闭占用端口的程序后重新从托盘打开管理页。

页面令牌每次启动更新，因此重启程序后需要从托盘重新打开。浏览器收藏的地址不会保存令牌。令牌仅用于本地接口访问，不是云账号。

## 前端开发与构建

前端为 Vue 3、Vue Router、Vite 和 TypeScript。需要 Node.js 22.12+ 及 pnpm 11，运行打包后的软件不需要 Node.js。

```powershell
cd Web
pnpm install --frozen-lockfile
pnpm run build
```

先构建前端，再通过 VS2022 编译解决方案。项目会将 `Web/dist` 复制为输出目录中的 `Web` 文件夹；发布时需要一起保留静态文件、程序集和 Resources。

每次编译都会重新扫描前端构建产物，自动更新带哈希的 JS/CSS 文件名。更新项目配置后，已打开的 VS 若仍提示旧文件不存在，请重新加载项目后再生成；无需清空数据库或补回旧资源文件。

开发时执行 `pnpm dev`，默认监听 `127.0.0.1:5173`，将 `/api` 代理到桌面程序。首次开发授权可从正常管理页的浏览器开发者工具读取当前标签的 `sessionStorage.getItem('toastfish-token')`，通过开发页 URL 片段 `#token=...` 传入；勿提交或分享该令牌。开发代理只重写已限定的本机请求来源。

前端无 CDN，发布后可以离线访问页面；单词发音仍优先请求有道，失败时使用本机语音。

## 验证

当前数据库默认只读约定优先。以下旧版管理检查脚本会创建并写入测试数据库，不能未经对具体写入操作的明确授权自动运行；前端升级验证改用 `Web` 目录的 `pnpm test`，详见 [前端升级说明](frontend-upgrade.md)。

```powershell
./Tests/Run-ManagementChecks.ps1
./Tests/Run-LearningToastChecks.ps1
```

管理测试在编译输出目录创建隔离的临时数据库，验证迁移、逐次保存、写入失败回滚、暂停恢复、测验解析、去重、导入、备份恢复和旧版迁移，不操作真实用户数据库。

编译管理测试后，可执行 `bin/ManagementDebug/ToastFish.ManagementChecks.exe --real-seed`，额外验证仓库完整词库的迁移。`--serve` 仅用于测试：运行隔离数据库上的本地服务，凭据存储于同一测试输出目录的 `browser-context.json`，测试后应停止该进程。

## 接口约定

- 所有 `/api/*` 请求需要 `Authorization: Bearer ...`，不开放 CORS。
- 读取使用 GET；变更使用 POST 与 JSON。接口仅绑定回环地址，静态资源只开放构建资源。
- 主要资源：`dashboard`、`books`、`words`、`records`、`sessions`、`settings`、`imports`、`exports`、`backups`。
- 错误返回 JSON `{ "error": "说明" }`；参数错误 400、凭据失效 401、来源错误 403、状态冲突 409。
- 统计以本地时区划分日期，周一开始；新学与复习按词去重，操作次数逐次累计，重学不计作首次新学。
- 本期保留现有 SM2plus 评分算法，不将“进入复习”标为“已经掌握”。
